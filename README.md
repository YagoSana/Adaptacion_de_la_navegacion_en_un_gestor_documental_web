# Adaptacion_de_la_navegacion_en_un_gestor_documental_web

## Repositorio del código empleado para el desarrollo del prototipo

El proyecto consiste en el diseño y desarrollo de un sistema de gestión documental web que incluya una estrategia adaptativa que permita reconfigurar la navegación en base a la popularidad entre los recursos. La relevancia de cada documento permitirá adaptar dinámicamente los enlaces relacionados o reordenar los resultados de búsqueda para destacar aquellos recursos que son más relevantes en la práctica, mejorando la navegación y el acceso a contenido útil a los usuarios.
